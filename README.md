# Assessoria Unite Rise | Apresentação Comercial Oficial

> Apresentação executiva institucional para alinhamento estratégico, reuniões comerciais via Google Meet e apresentação de planos para negócios locais.

🌐 **Acesse online:** [https://eudaniellinharesmkt-sys.github.io/apresentacao-unite-rise/](https://eudaniellinharesmkt-sys.github.io/apresentacao-unite-rise/)

## 🎯 Objetivo
Proporcionar uma experiência visual de alta conversão para o closer e a equipe comercial conduzirem diagnósticos estratégicos e apresentarem a infraestrutura de vendas da Assessoria Unite Rise diretamente com clientes.

- **Slide 3:** O Método Unite Rise - Direcionamento multicanal baseado no nicho
- **Slide 4:** Apresentação dos Planos e Entregáveis (Plano 1, Plano 2, Plano 3)
- **Slide 5:** Tabela de Valores e Ancoragem Estratégica
- **Slide 6:** Alinhamento Contratual - Política Comercial de Implementação Imediata

## 🚀 Recursos Técnicos
- **URL Pública com Navegação por Hash:** Permite enviar links diretos para cada slide (ex: `.../#slide-5` para abrir na tabela de valores).
- **Botão de Copiar Link Integrado:** Botão discreto no cabeçalho e nos controles para copiar o link exato do slide atual com notificação visual.
- **Suporte Mobile e Touch Gestures:** Navegue passando o dedo (swipe) para esquerda ou direita no celular ou tablet.
- **Modo Tela Cheia:** Tecla `F` ou botão nos controles para apresentação imersiva em chamadas de vídeo.
- **Atalhos de Teclado:**
  - `→` / `Espaço` / `PageDown`: Próximo slide
  - `←` / `PageUp`: Slide anterior
  - `Home`: Primeiro slide
  - `End`: Último slide
  - `F`: Ativar/Desativar tela cheia
